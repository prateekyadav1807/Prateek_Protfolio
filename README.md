# Prateek Yadav — Portfolio

A premium, modern, and highly interactive personal portfolio website built with React + Vite, Tailwind CSS, and Framer Motion.

## Features

- 🌙 Dark / Light theme toggle
- ✨ Framer Motion scroll-reveal animations
- 🎨 Glassmorphism UI with gradient accents
- 📱 Mobile-first responsive design
- 🚀 Loading screen with animated intro
- 🗂️ Project detail modals
- 📊 Animated stat counters
- ♿ Accessible markup
- ⚡ Vite-powered fast builds

## Sections

1. **Hero** — Animated intro, CTA buttons, particle background
2. **About** — Professional summary, education timeline
3. **Skills** — Interactive category cards with tech pills
4. **Projects** — Showcase cards with detail modals
5. **Achievements** — Animated counters, coding journey timeline
6. **Contact** — Contact form + social links

## Getting Started

### Prerequisites
- Node.js 18+ and npm

### Install & Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

### Build for Production

```bash
npm run build
npm run preview
```

## Tech Stack

- **React 18** + **Vite 5**
- **Tailwind CSS 3**
- **Framer Motion 11**
- **React Icons 5**
- **React Router DOM 6**

## Customization

All personal data is centralized in `src/data/portfolio.js` — update your name, links, projects, and skills there.

To add a real resume download, place your `resume.pdf` in the `public/` folder.
